Proyek ini bertujuan melakukan Exploratory Data Analysis (EDA) pada data listing properti yang dikumpulkan oleh PT Ray Pink Property Indonesia (RPPI) untuk mendukung pengambilan keputusan strategis manajemen. Analisis difokuskan pada kualitas data, karakteristik rumah yang paling laku, perbandingan harga antar kota, serta rekomendasi lokasi ekspansi kantor cabang dan strategi investasi jangka pendek.
