# Studi Case
Proyek ini bertujuan melakukan Exploratory Data Analysis (EDA) pada data listing properti yang dikumpulkan oleh PT Ray Pink Property Indonesia (RPPI) untuk mendukung pengambilan keputusan strategis manajemen. Analisis difokuskan pada kualitas data, karakteristik rumah yang paling laku, perbandingan harga antar kota, serta rekomendasi lokasi ekspansi kantor cabang dan strategi investasi jangka pendek.
# Tujuan
- Evaluasi kualitas dan kesiapan data perusahaan
- Identifikasi pola harga dan karakteristik rumah yang dominan
- Perbandingan pasar properti antar kota
- Rekomendasi lokasi cabang baru
- Rekomendasi peluang investasi properti
# Dataset dan Variabel
Dataset berisi informasi rumah yang dijual di beberapa kota di Indonesia dengan variabel utama seperti luas tanah dan bangunan, jumlah kamar, lokasi, sertifikat, harga, dan tanggal listing.
# Metodologi
Pendekatan yang digunakan adalah Exploratory Data Analysis (EDA) dan Decision Tree dengan tahapan:
- Pemeriksaan kualitas data (missing values, duplikasi, outlier)
- Pembersihan dan standardisasi data
- Feature engineering sederhana (harga per m², segmentasi harga)
- Analisis deskriptif dan visualisasi
# Temuan Utama
- Segmen properti yang paling banyak dijual adalah rumah low-end (< 1 Miliar Rupiah).
- Luas bangunan dan harga per meter persegi menjadi faktor dominan dalam karakteristik rumah yang laku.
- Kabupaten Bogor – Barat menunjukkan kombinasi pasar aktif, harga terjangkau, dan dominasi segmen massal.
- Terdapat perbedaan harga yang signifikan antar kota.
